# Редизайн sh17.ru — Спортивная школа №17, Томск

Кликабельный макет нового сайта на чистых HTML/CSS/JS. Контент, составы, матчи и фото взяты с текущего sh17.ru (ноябрь 2026); картинки подгружаются напрямую с sh17.ru.

## Как открыть

```
python -m http.server 5517
```

Дальше откройте http://localhost:5517 (в Claude Desktop есть готовая конфигурация `.claude/launch.json` с именем `sh17`).

| Файл | Что внутри |

## Дизайн-система

- **Цвета.** Красный `#E31E24` из логотипа — только для главного действия и ключевых акцентов. Тёплая светлая шкала для контента, тёмная («манеж ночью») — для героя, матч-центра и подвала.
- **Шрифты.** Fira Sans Extra Condensed (заголовки, счёт, цифры) и Golos Text (текст и интерфейс). Оба бесплатные, с кириллицей.
- **Фирменная деталь.** Крупные цифры года рождения — так школа называет свои команды: карточки команд, шапка команды, подбор группы, фоновые цифры в шапках страниц.
- Все стили и токены лежат в `assets/css/style.css`, общие шапка, подвал и компоненты — в `assets/js/app.js`, данные — в `assets/js/data.js`.

## Что взято из референсов

- **Liverpool, Juventus:** истории в герое с вкладками и прогресс-баром.
- **Barça, PSG, Ajax:** матч-центр в виде горизонтальной ленты с фильтром по командам.
- **We Make Footballers:** постоянная кнопка «Записаться» и подбор группы по возрасту.
- **Академия «Краснодара»:** отдельные варианты входа по возрасту и для девочек.
- **Juventus Next Gen:** путь игрока по этапам.
- **Barça:** состав, сгруппированный по позициям.
- **Liverpool, Juventus:** юридические разделы вынесены в подвал и в мега-меню «О школе».
- Мобильная нижняя навигация, как в приложениях клубов.

## Обязательное для сайта школы

Версия для слабовидящих (переключатель в шапке и в подвале, запоминается), согласие на cookie, политика ПДн, баннер «Госуслуги. Решаем вместе», оценка качества услуг, все разделы «Сведений об образовательной организации».

## Что сделать при переносе на рабочий сайт

1. Шапку и подвал перенести в серверные шаблоны, данные из `data.js` брать из базы сайта.
2. Добавить в CMS поле «обложка новости без текста». Сейчас текст вшит в картинки, и макет вырезает из них фото через CSS (`.crop`).
3. Подключить формы (заявка, обратная связь) к почте или CRM. Сейчас они только показывают сообщение об успехе.
4. Заменить заглушки файлов в «Документах» и «Сведениях» реальными документами.
5. Для команд без фото показывается щит школы с годом; лучше добавить командные фото.
